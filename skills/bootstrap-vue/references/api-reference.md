## Composables

- `useBreadcrumb`: global breadcrumb state helper.
- `useColorMode`: global or targeted color theme control.
- `useModal`: programmatic modal creation and control.
- `usePopover`: programmatic popover and tooltip control.
- `useScrollspy`: scroll-driven active navigation tracking.
- `useToast`: programmatic toast creation and control.
- `useToggle`: show, hide, or toggle a targetable component.
